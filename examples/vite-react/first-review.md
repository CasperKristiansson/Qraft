# Your first Qraft review

This small cart deliberately leaves room for feedback. It never places an order or charges money.
Your review is saved in review.local.md; restarting pnpm demo preserves that file.

## Cart

- [ ] Change quantity and check the total
  Use the + and − controls beside the chair. The displayed quantity changes.
  The summary currently stays fixed. Add a note describing the expected total behavior.
- [ ] Attach feedback to the quantity control
  Write a note, choose Attach element, and select the + button in the cart.
  Submit it and check that your note includes context identifying the selected element.
- [ ] Try the quantity controls with a keyboard
  Use Tab to reach the quantity controls, then Enter or Space to change quantity.
  Check whether the focus indicator and controls are comfortable to use.

## Finish the review

- [ ] Review the cart at a narrow browser width
  Use your browser's responsive mode around 390 CSS pixels wide.
  Check that the cart and Qraft remain usable; leave a note about anything that gets in the way.
- [ ] Hand the observations back to your coding agent
  Open examples/vite-react/review.local.md in your editor to read the saved notes and statuses.
  Keep this toy checkout local. Skip this check if you only wanted to try the drawer.
